# @nexora.ts/ui

Reusable React components for the Nexora dashboard.

```tsx
import {
  SettingsCard,
  StatCard,
  Switch,
  ServerSelector,
  GuildSidebar,
  Modal,
  DataTable,
  ChannelPicker,
  RolePicker,
  UserPicker,
} from '@nexora.ts/ui';
```

Built for Tailwind CSS. Peer dependency: React 18+.

Plugins can reuse these components for consistent dashboard UX.

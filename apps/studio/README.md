# Nexora Studio

Local **Developer Center** for your Nexora bot project.

```bash
pnpm --filter @nexorajs/studio dev
```

Opens **http://localhost:3002** and proxies `/api` to the Studio API (`@nexorajs/dev-server` on `:3920`).

This is **not** the public documentation site (that lives on GitHub Pages via `apps/docs`).

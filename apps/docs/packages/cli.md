# create-nexorajs

CLI to scaffold a new Nexora bot project.

```bash
npx create-nexorajs my-bot
```

Prompts for bot name, database, dashboard, Docker, linting, GitHub Actions, and examples.

Also exposes `nexora` for plugin management (WIP: `add`, `remove`, `list`, `dev`).

See [Quick start](../guide/quick-start.md).

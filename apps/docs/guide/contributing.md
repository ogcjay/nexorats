# Contributing

Nexora grows when the community uses it, extends it, and improves it.

## How to help

1. Report bugs with the issue templates
2. Improve docs (this site lives in `apps/docs`)
3. Fix DX pain points in core packages
4. Publish plugins others can install

Questions and support: join the [Discord server](https://discord.gg/fHbCrdHnms) (maintainer: **ogcjay**).

Full guide: [CONTRIBUTING.md](https://github.com/ogcjay/nexorajs/blob/main/CONTRIBUTING.md) on GitHub.

## Docs contributions

```bash
pnpm --filter @nexora.ts/docs dev
```

Edit Markdown under `apps/docs/`. After merge to `main`, GitHub Pages rebuilds automatically.

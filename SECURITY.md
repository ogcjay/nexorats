# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report them privately via one of:

- GitHub Security Advisories (preferred): **Security → Report a vulnerability** on this repository
- Email: security@nexora.dev (update this address after creating the org)

Include:

1. Description of the vulnerability
2. Steps to reproduce
3. Affected package / version
4. Potential impact
5. Suggested fix (optional)

We aim to acknowledge reports within **72 hours** and provide a status update within **7 days**.

Please give us reasonable time to publish a fix before any public disclosure.
